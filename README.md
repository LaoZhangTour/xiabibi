## 🎉 欢迎来到 XiaBiBi！

我们鼓励你卸下伪装，畅所欲言，但 **“瞎”不代表没有底线，“逼逼”也不是为了制造垃圾**。为了让大家都能有个舒心的交流环境，请花两分钟看看这份“生存指南”。

---

### 一、我们的江湖规矩（核心价值观）

1. 🤝 **嘴下留情，互相尊重**：你可以吐槽、可以抬杠、可以不同意对方的观点，但绝不能进行人身攻击、辱骂或歧视。把脾气留给生活，把友善留给这里。
2. 🐂 **吹牛可以，造谣不行**：欢迎分享真实的经历、见解甚至失败教训。但严禁编造虚假事实、传播谣言或发布恶意引战的内容。
3. 🌍 **求同存异，包容多元**：每个人的认知都有局限，遇到分歧时，请记住我们只是在网上“瞎逼逼”，没必要争个你死我活。

---

### 二、发帖姿势要帅（内容规范）

| 规范项 | 详细说明 |
| :--- | :--- |
| 🏷️ **标签别乱贴** | 发帖时请务必选对分类标签（如 `提问 Question`、`教程 Tutorial`、`闲聊 Chat` 等）。拒绝无意义的“震惊体”标题。 |
| 🎨 **排版看着舒服** | 鼓励图文并茂，长文请善用分段、列表和代码块。满屏密密麻麻的文字不仅费眼，还容易被当成机器刷帖。 |
| 🔍 **伸手党退散** | 遇到问题先搜搜历史帖子。提问时提供足够的上下文信息，别人帮你解答后，别忘了点个赞或回一句感谢。 |
| ©️ **版权是红线** | 转载或引用他人作品请注明出处。尊重原创，是对创作者最基本的礼貌。 |

---

### 三、绝对高压线（零容忍行为）

> ⚠️ **警告：** 以下行为将导致帖子被秒删，账号直接进小黑屋！

- 🚫 涉政、涉黄、涉赌及其他违反国家法律法规的内容。
- 🚫 发广告、搞黑产、恶意引流或发布钓鱼链接/病毒软件。
- 🕵️‍♂️ 侵犯他人隐私（如人肉搜索、未经允许曝光私人聊天记录）。
- 🤖 滥用脚本爆吧、恶意刷帖干扰论坛正常运行。

### 四、违规怎么罚？

我们实行阶梯式处罚机制：

<details>
<summary><strong>⚡ 轻微违规（点击展开详情）</strong></summary>
<br>
如水帖、小摩擦等：<code>警告提醒</code>、<code>折叠帖子</code>、<code>短期禁言（1-7天）</code>让你冷静一下。
</details>

<details>
<summary><strong>💥 严重违规（点击展开详情）</strong></summary>
<br>
如恶意引战、屡教不改等：<code>删除违规内容</code>、<code>长期禁言</code>、<code>清空积分</code>。
</details>

<details>
<summary><strong>☠️ 触碰红线（点击展开详情）</strong></summary>
<br>
涉及绝对高压线的行为：<code>永久封停账号</code>，并视情况屏蔽 IP 地址。
</details>

### 五、遇到问题或有建议？找我们聊聊

如果你认为自己的帖子被误删，或者对我们的平台有任何反馈，欢迎通过以下方式联系我们：

- 💬 **论坛日常反馈**：如果是关于帖子申诉、功能建议或 Bug 反馈，请在论坛内使用 `Bug` 或 `Suggestion` 标签发帖，管理团队会公开跟进处理。
- 🛠️ **GitHub Issue 反馈**：如果遇到了网页加载异常、代码报错等底层技术问题，请点击前往 [GitHub Issues 反馈页](https://github.com/LaoZhangTour/xiabibi/issues) 提交 Issue。
- ✉️ **发送站内信**：如果不想公开讨论，也可以直接发送站内信给管理员。
